why a dedicated miner

Same reward ceiling. None of the leakage.

The on-chain pace cap means everyone mines at the same rate — so it's not a speed race, it's a timing race. Browser tabs lose rewards to RPC lag and missed submit windows. derpminer doesn't.

01

Scheduling, not grinding

Precomputes each shift's solution once in a worker thread, sleeps until the pace cap clears, then submits inside the 150-second certified window — capturing the full tick-based reward.

02

RPC-resilient

A health-scored pool of your endpoints with automatic failover. Time-critical clock-outs are broadcast to every healthy RPC at once, with gas-bump retries and a serial nonce queue.

03

Headless & cold

Pure CLI on your machine or a small server — no browser, no popups. Your main wallet key never touches the tool; mining uses a throwaway key the contract restricts on-chain.

the important part

It cannot drain your wallet.

The safety guarantee is enforced on-chain — it holds even if you don't trust the code.

  • Your owner key is never entered, stored, or seen by the tool. You sign a one-time budgeted grant in your own browser wallet.
  • The hot key it mines with can only clock in (from a tank you fund, capped by maxFee) and clock out (which always pays your wallet). It can't transfer, approve, withdraw the tank, or re-grant itself.
  • Worst case if the key leaks: an attacker wastes your budgeted fees. Your wallet, NFTs, DERP, and tank are unreachable.

install

Zero to mining.

You bring a PitBoy on Robinhood Chain, ~60–75 APE, and a little ETH for gas. Then:

# 1 · install
git clone https://github.com/hhehadhalcvasdnjv/derpminer && cd derpminer
npm install && npm run build
alias derpminer="node $PWD/dist/cli.js"
# 2 · look (free), configure, activate + grant in your browser wallet, run
derpminer quote pitboys 742 0
derpminer init
derpminer activate pitboys <TOKEN> 0 --web
derpminer shadow-setup --deposit 15 --budget 100 --max-fee 0.2 --days 14 --web
derpminer run              # headless miner + dashboard on :8787

how mining works

Quickest hash wins.

Proof: sha256(mine ++ tokenId ++ ticks ++ prev ++ seed) must end in 0x5d3129. The seed is set by the contract at clock-in, so nothing can be pre-ground.

Reward: the quickest hash prints the most (up to 4 444 DERP), decaying to a 44 floor. The live Index (0–90) compresses rewards when the floor runs hot — derpminer computes the honest expected print over the hit distribution, not the naive floor.
